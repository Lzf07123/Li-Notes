# Li&Notes 品牌与产品意图

> 版本：v2.0 ｜ 日期：2026-10-23 ｜ 状态：文章域分离完成
> 来源：由原 Li&Blog 品牌方案收敛，只保留文章站所需事实

## 1. 定位

- 一句话定位：**一次记录，见证每一步成长**。
- 产品承诺：每一篇都是真实足迹，每次回顾都有迹可循。
- 人格关键词：安静、可信、克制、清晰、可靠。
- 目标：让完整学习笔记被稳定写作、检索、归档和长期保存。
- 明确不是：个人主页、项目展示站、时间线、友链目录、资源导航或社区。

## 2. 内容边界

- 只保留文章、标签、归档、搜索及后台编辑。
- 不展示 Hero 技能徽章、项目卡、时间线、关于我、资源页和友情链接。
- 首页用紧凑的档案摘要衔接笔记流，不承担个人营销或项目介绍。
- 文章页可包含目录、代码复制、上一篇/下一篇和相关笔记。

## 3. 视觉继承

忠实继承 Li& 家族的海玻璃主色和淡色科技感：

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F6FBF9` | `#3A3F45` |
| 表面 | `#FFFFFF` | `#434950` |
| 正文 | `#35423F` | `#F0F2F4` |
| 次要文字 | `#64736C` | `#B8C0C7` |
| 主色 | `#25786D` | `#7FD4C6` |
| 主色软底 | `#D9F4EE` | `rgba(127,212,198,.16)` |

- 令牌唯一定义在 `themes/blog-theme/static/css/tokens.css`。
- `--liblog-*` 和主题目录名是兼容命名；对外产品名固定为 Li&Notes。
- 正文对比度 ≥ 4.5:1，交互触达 ≥ 44px。

## 4. 体验原则

- 阅读优先：正文、目录、代码与脚注优先于装饰。
- 动效克制：文章页不加载远程或运行时效果；尊重 `prefers-reduced-motion`。
- 搜索本地：只读取构建期索引，不上传查询内容。
- 导航精简：首页、文章、归档、搜索。
- 空状态清晰：给出原因和返回首页动作。
- 公开站零交互栏目：无评论、留言、注册或用户输入。

## 5. 文案口径

- 用“笔记/文章”，不用“博客项目/项目集/历程/友情链接”。
- 所有可见文案走 `config/strings.yaml`，禁止散落在模板。
- 站点名称、版权、备案走 `config/brand.yaml`。
- 作者姓名和外部身份链接走 `config/profile.yaml`。
